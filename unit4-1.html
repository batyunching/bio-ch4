01

刺激與反應

概念卡

刺激與反應

受器・動器
點一下翻面

受器接收刺激，動器產生反應

構造功能位置／例子
受器接收刺激眼（光線）、耳（聲音）、鼻（氣味）、舌（味道）、皮膚（冷、熱、觸、壓、痛）
動器產生反應肌肉和腺體
  • 沙子跑進眼睛：不斷眨眼（肌肉），淚腺分泌更多淚液把沙子沖走（腺體）。
  • 看到球靠近：手部肌肉收縮才能接住球。
⚠ MYTH ALERT 迷思小警報動器只有肌肉　→　腺體也是動器！流眼淚、分泌唾液都是「反應」。
課本 P.130–131

神經元

概念卡

神經元

神經系統的基本單位
點一下翻面

神經元＝神經細胞

神經元（神經細胞）是神經系統的基本單位，由兩部分組成：

構造功能
細胞本體內有細胞核，能調節神經元的代謝、整合訊息
神經纖維接收及傳導訊息
⚠ MYTH ALERT 迷思小警報神經纖維是另一種細胞　→　神經纖維是神經元的一部分，整個神經元只是一個細胞。

03

神經系統與中樞神經

概念卡

神經系統的組成

中樞神經・周圍神經
點一下翻面

中樞神經＋周圍神經

系統包括
中樞神經腦（大腦、小腦、腦幹）和脊髓，都有骨骼保護（頭骨、脊椎）
周圍神經與腦相連的 12 對腦神經、與脊髓相連的 31 對脊神經

中樞神經和周圍神經共同完成傳遞神經訊息的工作。

⚠ MYTH ALERT 迷思小警報脊髓屬於周圍神經　→　脊髓是中樞神經；和脊髓相連的「脊神經」才是周圍神經。
課本 P.132

中樞神經的功能

大腦・小腦・腦幹・脊髓
點一下翻面

四個中樞，各司其職

構造功能
大腦掌管感覺、運動、意識、記憶、思考和語言。左半球控制右半身，右半球控制左半身
小腦協調全身肌肉，維持身體平衡
腦幹控制呼吸、心跳、血壓、唾液分泌，是生命中樞
脊髓把頸部以下的訊息上傳到腦、把腦的命令下傳；也是四肢的反射中樞
⚠ MYTH ALERT 迷思小警報小腦控制呼吸心跳　→　小腦管平衡；呼吸、心跳是腦幹（生命中樞）的工作。
課本 P.132–133

04

神經傳導途徑

概念卡

神經傳導途徑

感覺神經元・運動神經元
點一下翻面

訊息怎麼跑？

刺激 → 受器 → 感覺神經元 → 中樞神經 → 運動神經元 → 動器 → 反應

神經元傳導方向
感覺神經元受器 → 中樞神經
運動神經元中樞神經 → 動器

就像結帳：掃描器（受器）讀到條碼 → 電腦（中樞神經）處理 → 印表機（動器）印出明細。

⚠ MYTH ALERT 迷思小警報運動神經元把訊息傳到腦　→　「感覺」往中樞送，「運動」從中樞往動器送。
課本 P.134

    意識反應與反射

    概念卡

    意識反應

    需要經過大腦整合
    點一下翻面

    經過大腦想一想才行動

    意識反應須經過大腦的整合。例：看到同學迎面走來，揮手打招呼。

    受器（眼睛內）→ 感覺神經元 → 大腦 → 脊髓 → 運動神經元 → 動器（手的肌肉）

    ⚠ MYTH ALERT 迷思小警報意識反應不經過脊髓　→　大腦發出的命令要經過脊髓，再由運動神經元傳到手。
    課本 P.134–135

    反射

    不須經過大腦的快速反應
    點一下翻面

    來不及想，身體先動

    反射不須經過大腦意識，可縮短反應時間，用來應付緊急狀況、降低傷害、節省腦力。

    控制中樞例子
    腦幹不經意的眨眼、咳嗽、唾液分泌、瞳孔遇強光縮小
    脊髓手摸到熱茶壺立刻縮回、腳踩到尖物立刻縮回

    摸到熱茶壺：縮手是反射（脊髓）；之後感覺到痛、撫摸檢查是意識反應（大腦）。

    ⚠ MYTH ALERT 迷思小警報反射不經過中樞神經；痛覺在脊髓產生　→　反射仍經過中樞（腦幹或脊髓），只是不經大腦；「痛」的感覺在大腦產生。
    課本 P.136–137
